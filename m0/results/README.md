# m0/results

The M0 probes (`m0/probes/`) and `scripts/codex-host-e2e.sh` write raw protocol logs here. They are not
published: real agent runs load local context (memories, skill lists, home paths) and the logs record it.
The conclusions drawn from them are in `docs/m0/M0_RESULTS.md` and `docs/e2e/E2E_RESULTS.md`.
